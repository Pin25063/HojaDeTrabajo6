## Especificaciones
Para garantizar el manejo correcto de caracteres con tilde, se utiliza `System.setOut` configurado con codificación UTF-8, lo que permite que la salida del programa se imprima correctamente.  
Sin embargo, también es necesario que la terminal esté configurada para soportar UTF-8. En sistemas Windows, activarlo con el siguiente comando:  
chcp 65001
